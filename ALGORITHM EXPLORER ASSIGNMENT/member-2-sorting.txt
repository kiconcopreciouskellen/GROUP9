WHAT I BUILT
Three sorting algorithms . Each one sorts an array, writes every step to the log,
and counts its operations. None of them use a built-in sort function.

1. Bubble Sort
   Compares two neighbouring numbers and swaps them if they are in the wrong order. It repeats this
   until no swaps are needed. If a full pass has no swaps, it stops early.

2. Quick Sort 
   Picks a pivot number (in this case the middle one), puts smaller numbers on its left and larger numbers on its
   right, then repeats the same on each side.

3. Merge Sort
   Splits the array in half again and again until each part has one number, then joins the parts
   back together in order.

WHAT COUNTS AS ONE OPERATION
- Bubble Sort and Quick Sort: one comparison, or one swap.
- Merge Sort: one comparison, or one number written back into the array.
Using the same idea in all three means their counts can be compared fairly.

SPEED (n = number of values)
                Best         Average      Worst        Extra memory
Bubble Sort      n            n x n        n x n        none
Quick Sort       n log n      n log n      n x n        small
Merge Sort       n log n      n log n      n log n      n

Bubble Sort is slow for large inputs. Quick Sort and Merge Sort stay fast.
